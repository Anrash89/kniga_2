# Зайка ищет попу и идет на горшок — интерактивная книга

## Что внутри
- готовый HTML-проект для GitHub Pages
- плавное перелистывание
- интерактивные страницы с повторным открытием/закрытием
- адаптация под телефон и компьютер

## Интерактивные страницы
- Страница 5: сначала `5-1`, по кнопке открывается `5-2`
- Страница 8: сначала `8`, по кнопке открывается `8-1`
- Страница 10: сначала `10-1` (в проекте это `page-10-state-a.png`), по кнопке открывается `10`

## Публикация на GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Залей в него содержимое этой папки.
3. В GitHub зайди в **Settings → Pages**.
4. В **Build and deployment** выбери:
   - **Source** → `Deploy from a branch`
   - **Branch** → `main` и `/root`
5. Сохрани настройки.
6. Через минуту откроется ссылка на книгу.

## Локальный запуск
Открой `index.html` в браузере.
