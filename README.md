# Интерактивная книга «Зайка ищет попу»

Готовый проект для GitHub Pages.

## Как загрузить на GitHub

1. Создай новый репозиторий на GitHub.
2. Загрузи в него все файлы из этой папки: `index.html`, папку `assets` и `README.md`.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Source: Deploy from a branch.
5. Branch: `main`, Folder: `/root`.
6. Нажми Save.

Через минуту GitHub даст ссылку на электронную книгу.

## Интерактивные страницы

- Страница 5: сначала стоит версия с закрытым окошком `page-05-closed.png`, по кнопке открывается `page-05-open.png`.
- Страница 8: сначала Зайка в штанишках `page-08-pants.png`, по кнопке меняется на `page-08-no-pants.png`.
- Страница 9: сначала пустой горшочек `page-09-empty.png`, по кнопке меняется на `page-09-filled.png`.

Все картинки лежат локально в папке `assets`, интернет для работы книги не нужен.
